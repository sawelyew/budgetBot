# BudgetBot

Telegram-бот для учёта расходов и автоматизации обработки заявок на возврат средств с интеграцией в PostgreSQL и S3-хранилище (MinIO).

---

## Технологический стек

* **Язык:** Python 3.13
* **Фреймворк:** aiogram 3.x
* **База данных:** PostgreSQL 16 (SQLAlchemy / asyncpg)
* **Хранилище файлов:** MinIO (S3 API)
* **Контейнеризация:** Docker & Docker Compose

---

## Основные возможности

* **Учёт расходов:** Пошаговая подача заявок на возврат средств через FSM.
* **Прикрепление чеков:** Загрузка и сохранение медиафайлов в S3-хранилище (MinIO).
* **Уведомления:** Автоматическая отправка сформированных заявок в чат администраторов/финансистов.

---

## Команды бота
* **/start**: Регистрация пользователей
* **/new_expense**: Создание заявки на выплату
* **/requisites**: Просмотр текущих реквизитов по умолчанию и их смена

Изменение ролей пользователей осуществляется администраторами с помощью команды:
```text
/setrole <user_id> <role>
```
### Доступные роли:
* applicant — обычный пользователь (создание заявок).
* financier — финансист (просмотр и обработка заявок).
* admin — администратор (управление правами пользователей).
### Пример использования:
```text
/setrole 123456789 financier
```

## Быстрый запуск (Docker Compose)

Самый простой способ поднять всё окружение (БД, MinIO и самого бота) одной командой:

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/sawelyew/budgetBot.git](https://github.com/sawelyew/budgetBot.git)
   cd BudgetBot
   ```
2. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env
   ```
3. **Запустите проект:**
   ```bash
   docker compose up -d --build
   ```
## Локальная разработка (Local Development)
1. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate  # macOS/Linux
   # .venv\Scripts\activate   # Windows
   ```
2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Запустите только инфраструктуру (БД + MinIO) в Docker:**
   ```bash
   docker compose up db minio -d
   ```
4. **Запустите бота локально:**
   ```bash
   python3 -m app
   ```
